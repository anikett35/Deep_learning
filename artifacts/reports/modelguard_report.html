1. Problem Statement

Production deep neural networks deployed behind black-box query APIs represent substantial capital investments in training data curation, architecture design, and compute. However, these models are acutely vulnerable to model extraction (theft) attacks, where an unauthenticated adversary queries the public prediction endpoint with unlabeled domain samples to train a substitute classifier. Traditional defensive measures like rate-limiting degrade customer utility and can be circumvented via distributed botnets. ModelGuard provides an active, cryptographically grounded watermarking mechanism that survives black-box query-response extraction while offering exact statistical proof of ownership.

2. Threat Model

We adopt the realistic black-box adversary model:

  • Attacker Access: Query-only access to POST /predict (input image → class prediction and soft probability vectors).
  • Attacker Knowledge: The attacker has zero knowledge of the victim's internal architecture, model weights, training hyper-parameters, loss functions, or trigger set.
  • Adversary Topology: The attacker initializes and trains a structurally distinct substitute network (ThiefCNN) from scratch.
  • Adaptive Capability: The adversary may perform clean-data fine-tuning on their stolen model in an attempt to unlearn the embedded watermark shortcut.

5. Watermark Trigger Engine Design

The watermark mechanism generates 80 secret visual probes using localized $4 imes 4$ pixel stamps embedded in the bottom-right corner with a high-frequency cyan/magenta checkerboard pattern. Each trigger is mapped to target class airplane (Index 0). The trigger set is cryptographically hashed with SHA-256:

7. FastAPI Black-Box Model Service

The victim model is served via a production FastAPI application adhering strictly to black-box query constraints. Every incoming inference query is logged with a SHA-256 input hash, timestamp, response latency, and predicted class name. Secret triggers and weights are completely inaccessible through API endpoints.

8. Black-Box Extraction Attack Simulation

The adversary queries the victim service with unlabeled images sampled from the extraction pool. The adversary collects victim response labels to form a synthetic stolen dataset and trains a structurally distinct ThiefCNN from scratch without access to victim weights or triggers.

13. Limitations

Our empirical measurements reveal key limitations:

  • Clean Fine-Tuning Decay: Extensive fine-tuning on clean domain samples progressively decays the transferred watermark shortcut towards baseline null levels ($10\%$).
  • Capacity Trade-Off: Highly compact models experience a slight clean accuracy delta when jointly memorizing 80 complex shortcuts alongside standard CIFAR-10 features.

15. Experimental Conclusions

ModelGuard successfully demonstrates:

  1. Joint watermark embedding achieves 100% trigger memorization with measured clean accuracy trade-offs.
  2. Black-box model extraction involuntarily transfers the watermark behavior to heterogeneous substitute models with overwhelming statistical significance ($p < 10^-6$).
  3. Exact binomial testing provides mathematical proof of IP ownership without relying on heuristics or approximations.
